# 🏛️ बाणगंगा नगरपालिका - आन्तरिक नियन्त्रण तथा कर्मचारी प्रशासन प्रणाली
## Municipality Internal Administration & Employee Management System (`ePalika.com`)

नेपाल सरकार, लुम्बिनी प्रदेश, कपिलवस्तु जिल्लास्थित **बाणगंगा नगरपालिका**को आधिकारिक आन्तरिक नियन्त्रण प्रणाली।

---

## 🌟 मुख्य मोड्युलहरू (Key Modules Implemented)

1. **प्रशासनिक ड्यासबोर्ड (Interactive Administration Dashboard)**:
   - जम्मा कर्मचारी, स्थायी कर्मचारी, करार कर्मचारी, ज्यालादारी कर्मचारी संख्या।
   - वडा कार्यालय, दर्ता संघसंस्था, लैङ्गिक अनुपात (महिला/पुरुष), शाखागत र पदगत तथ्याङ्क।
   - हालसालै थपिएका कर्मचारी तथा प्रणाली अडिट गतिविधिहरू।

2. **कर्मचारी प्रशासन (Employee Management Module - PDF Reference Matched)**:
   - आधिकारिक फारमका सम्पूर्ण **३२ वटा फिल्डहरू** (फिल्ड, कोड, तह, सेवा, समूह, शैक्षिक योग्यता, शाखा, कार्यालय, स्थायी/करार, सेवाको किसिम, दरबन्दी, बहाल विदा, कोष नम्बरहरू, नियुक्ति मितिहरू, ठेगाना र सम्पर्क)।
   - **Show All Records, Search, Filterby MultiSelection, Excel, New, Save, Update, Delete, Print** एक्शन बार।
   - बहु-मापदण्ड फिल्टर प्यानल (शाखा, पद, तह, कार्यालय, प्रकार र लिङ्ग)।
   - कर्मचारी परिचय प्रोफाइल कार्ड तथा विस्तृत अभिलेख।

3. **पालिका प्रोफाइल (Municipality Profile)**:
   - पालिकाको नाम, ठेगाना, सम्पर्क, वेबसाइट, नगर प्रमुख, उप-प्रमुख, प्रमुख प्रशासकीय अधिकृत (CAO), सूचना अधिकारी विवरण तथा सार्वजनिक पृष्ठ।

4. **वडा कार्यालय व्यवस्थापन (Ward Offices - Wards 1 to 11)**:
   - वडा अध्यक्ष, वडा सचिव, सम्पर्क नम्बर, जनसंख्या, वडागत कर्मचारी संख्या र दर्ता संस्था विवरण।

5. **सार्वजनिक उपयोगिता तथा संस्था व्यवस्थापन (Institutions Management)**:
   - **सहकारी संस्था (Cooperatives)**
   - **खानेपानी उपभोक्ता समिति (Drinking Water)**
   - **सामुदायिक वन उपभोक्ता समूह (Community Forest)**
   - **संघसंस्था / गैरसरकारी (Organizations / NGOs)**

6. **मास्टर सेटिङ (Master Dropdown Management)**:
   - पद, तह, सेवा, समूह, शाखा/विभाग, कार्यालय, शैक्षिक योग्यता, सेवा प्रकार आदिको ड्रपडाउन व्यवस्थापन।

7. **प्रयोगकर्ता तथा पासवर्ड वितरण (User Auth & Password Distribution)**:
   - नयाँ प्रयोगकर्ता दर्ता, प्रयोगकर्ता संकेत (User ID), वर्ग (कर्मचारी, सहकारी, खानेपानी, वन, संघसंस्था), भूमिका छनोट, र १-क्लिक सुरक्षित पासवर्ड जेनेरेसन तथा SMS वितरण।

8. **भूमिकामा आधारित पहुँच नियन्त्रण (RBAC - 5 Roles)**:
   - `Super Admin`, `Admin`, `Employee`, `Ward User`, `Institution User`।

## 🚀 तत्काल कसरी चलाउने (How to Run Immediately on Windows)

कुनै अतिरिक्त सफ्टवेयर इन्स्टल नगरीकन तुरुन्तै परीक्षण गर्न:

1. रूट फोल्डरमा रहेको **`run_epalika.bat`** फाइलमा Double-Click गर्नुहोस्।
2. अथवा ब्राउजरमा `epalika/public/index.html` सिधै खोल्नुहोस्।
3. शीर्ष पट्टीमा रहेको **"भूमिका"** (Role Switcher) बाट ५ वटै भूमिकाहरू छनोट गरी फरक-फरक मेनु पहुँच र अधिकारहरू प्रत्यक्ष परीक्षण गर्न सक्नुहुन्छ।

## 💻 Laravel / MySQL सर्भरमा डिप्लोय गर्ने विधि (Server Deployment)

### आवश्यकता:
- PHP >= 8.2 (extensions: `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `curl`)
- MySQL 8.0+ / MariaDB
- Apache वा Nginx

### चरणहरू:
```bash
# १. डिरेक्टोरीमा जानुहोस्
cd epalika

# २. Database तयार गरी आयात गर्नुहोस्
mysql -u root -p epalika_banganga < database/sql/epalika_schema_and_data.sql

# ३. वातावरण फाइल कन्फिगर गर्नुहोस्
cp .env.example .env

# ४. Composer प्याकेजहरू स्थापना गर्नुहोस्
composer install --optimize-autoloader --no-dev

# ५. एप्लिकेसन की (Key) जेनेरेट गर्नुहोस्
php artisan key:generate

# ६. स्टोरेज लिंक गर्नुहोस्
php artisan storage:link

# ७. सर्भर सुरु गर्नुहोस्
php artisan serve
```
